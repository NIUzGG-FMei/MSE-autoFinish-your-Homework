# MSE-autoFinish-your-Homework

MSE 微课平台辅助插件（Chrome / Edge MV3）：一键补满学习时长、自动完成必做练习。

> 仅适配《农林院校专业学位研究生英语》课程及对应平台版本。平台大约每月更新一次，适配点失效时插件会自动降级为只读（只保留「扫描」「校验」）。

实现思路、踩坑和技术路线见博文：<https://2298321.xyz/posts/mse-microlesson-helper/>

## 安装

1. 下载或 clone 本仓库，放在一个固定文件夹（装好后不要移动/删除）。
2. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 登录平台、进入课程学习页，右下角会出现面板。

## 功能

| 按钮 | 作用 |
|---|---|
| 补满学习时长 | 读取当前累计值，只提交差额，补到要求值为止 |
| 自动答必做练习 | 仅处理「允许重做」的必做小节；不可重做的小节直接跳过 |
| 一键全自动 | 先补时长，再答练习 |
| 扫描（只读） | 列出含练习的小节、题型、题量、是否必做/可重做 |
| 校验（只读） | 统计已提交作答的对错与待批数量 |

建议顺序：先「扫描」→ 再「一键全自动」→ 最后「校验」。

## 文件

- `manifest.json`：插件配置（零权限，`world: "MAIN"`）
- `content.js`：全部功能代码
- `README.txt`：给同学看的详细使用说明

## 说明

- 插件不连接任何第三方服务器，所有请求都发往平台自身接口，使用你自己的登录态。
- 仅供学习交流，使用风险自负。
