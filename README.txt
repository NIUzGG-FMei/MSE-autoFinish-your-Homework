========================================
MSE-加速英语老师的消化系统！ v1.1.0
========================================

适用课程：courseId=1926《农林院校专业学位研究生英语》（西北农林科技大学，26年46班）
          courseId=1615
支持方式：课程 ID 白名单，面板底部会显示当前课程 ID 与是否受支持
适用平台：microlesson.rcgtjy.com
适用浏览器：Chrome / Edge 111 及以上版本


----------------------------------------
一、安装（约 1 分钟）
----------------------------------------
1. 把压缩包解压到一个固定文件夹，例如 D:\MSE微课助手
   注意：解压后文件夹里应该直接能看到 manifest.json 和 content.js
   装好之后不要删除或移动这个文件夹，否则插件会失效

2. 打开浏览器，地址栏输入：
   Chrome：chrome://extensions
   Edge  ：edge://extensions

3. 打开右上角（Edge 在左下角）的「开发者模式」开关

4. 点击「加载已解压的扩展程序」，选择第 1 步解压出来的文件夹

5. 安装完成。打开微课平台的学习页面，右下角会出现
   「MSE-加速英语老师的消化系统！」面板


----------------------------------------
二、使用
----------------------------------------
进入任意课程学习页（左侧有章节树的页面），右下角面板会自动出现。

  【补满学习时长】
     把每个小节、每个单元要求的观看时长直接补满，不需要真的挂机。
     一般 2~4 分钟跑完，日志里会逐条显示 从多少秒 → 多少秒。

  【自动答必做练习】
     自动完成所有「必做」练习：先取平台的标准答案，再按答案提交。
     客观题全部自动判分，主观题（翻译、写作）提交参考答案原文，
     由教师批阅，平台本身不自动判分。

  【一键全自动】
     先补时长，再答必做练习，一次跑完。

  【扫描】
     只读，列出所有含练习的小节：题型、题量、必做/选做、是否可重做。

  【校验】
     只读，统计已提交的作答：客观题对多少、错多少、主观题待批多少。
     如果发现错题会列出来。

  【停止当前任务】
     立即中断正在跑的任务，已完成的步骤不会回退。

建议顺序：先点【扫描】看一眼，再点【一键全自动】，最后点【校验】确认。


----------------------------------------
三、常见问题
----------------------------------------
Q：面板没出现？
A：确认当前页面地址是 microlesson.rcgtjy.com 的课程学习页，
   并且已登录。刷新页面试试。

Q：提示「检测到平台更新，部分功能不可用」？
A：平台改版了，插件的适配点失效。此时写操作按钮会变灰，
   只保留扫描和校验。请把面板日志里的 base.js / subject.js
   版本号发给作者，等更新版本。

Q：按钮点了没反应 / 一直是灰的？
A：先点【停止当前任务】再试；如果还不行，刷新页面。

Q：补时长会不会把学习时长记成很夸张的数字？
A：不会。插件先读当前累计值，只提交差额，精确补到要求值为止，
   不会超发。

Q：会不会把答错的记录留下？
A：不会。插件只处理「允许重做」的小节，流程是
   取答案 → 重新作答 → 按正确答案提交，不会留下错误作答。
   不允许重做的小节会被直接跳过。


----------------------------------------
四、注意事项
----------------------------------------
1. 仅适配白名单内的课程（courseId=1615 / 1926）。当前页面课程 ID 会显示在
   面板底部（如「课程 1926 ✓」）；不在白名单时显示 ✗，写操作自动置灰。
   新增课程需要改代码里的 supportedCourseIds 白名单。
2. 插件只向平台自身接口发送业务请求，使用你自己的登录态；唯一的对外请求
   是检查 GitHub 仓库上的版本号（version.json），不携带任何账号信息。
3. 插件不会自动修改自身文件。检测到新版本时只提示，更新动作由你手动完成。
4. 建议错峰使用，不要多个账号同时跑。
5. 本工具仅供学习交流，使用风险自负。


----------------------------------------
五、版本更新
----------------------------------------
插件加载后约 3 秒静默检查一次版本（30 分钟内不重复检查），
数据源是 GitHub 仓库根目录的 version.json，经 jsDelivr CDN 读取。

发现新版本时，面板顶部出现蓝色提示条「发现新版本 vX.Y.Z 点此更新」：
  1. 点击提示条 → 自动打开下载地址（zip 或仓库页面）
  2. 下载并解压，覆盖插件原目录
  3. 打开 chrome://extensions，点本插件的「重新加载」
  4. 回到课程页刷新，面板底部版本号变化即更新成功

检查失败（网络不通、CDN 不可达、格式异常）时完全静默，
不会弹窗、不会污染日志、不影响补时长和答题功能。

发布新版本时需同步修改四处：
  content.js 的 CFG.version、manifest.json 的 version、
  本文件末尾的版本号、version.json 的 version
version.json 的 version 必须大于用户当前版本，否则不会提示。
